# 🥗 Nutritional Diet Suggestion Expert System

## 📌 Project Overview
This project is a Python-based Nutritional Diet Suggestion Expert System that provides personalized diet recommendations and meal plans based on user input. It uses a knowledge base of food items and their nutritional values to calculate daily nutrient requirements and generate suitable meal plans. The application features a user-friendly graphical interface built using Tkinter.

---

## 🎯 Features
- 🧮 Calculate daily nutrient requirements based on user details (weight, height, age, gender)
- 🥦 Support for multiple diet types (Vegetarian, Non-Vegetarian, Vegan)
- 🍽️ Generate customized meal plans
- 📊 Nutrient-based food recommendations
- 🖥️ Interactive GUI using Tkinter

---

## 🛠️ Technologies Used
- Python
- Tkinter (GUI)
- Pillow (Image handling)
- Basic Data Structures (Dictionary for knowledge base)

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Nutritional-Diet-Suggestion-Expert-System.git
   cd Nutritional-Diet-Suggestion-Expert-System
2. **Navigate to the project directory:**
```bash
    cd Nutritional-Diet-Suggestion-Expert-System
```  
3. **Install the required packages:**
```bash
   pip install -r requirements.txt
```
4. **Run the script:**
```bash
   python diet_suggestion_app.py
```

## Customization

Feel free to customize the knowledge base and add more foods or nutrients based on your needs. The knowledge base is defined in the script as a dictionary, which can be easily modified.
